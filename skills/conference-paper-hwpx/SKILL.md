# 학술대회 논문 양식 작성 스킬

기관·학회 정보가 없는 범용 학술대회 논문 양식(`assets/template.hwpx`)에 내용을 채워 새 `.hwpx`를 만든다.
전역 **hwpx 스킬**(`~/.claude/skills/hwpx`)의 `fill_hwpx.py`를 재사용하므로 먼저 설치되어 있어야 하고, Python 3과 `lxml jsonschema Pillow`가 필요하다.

## 작성·디자인 규칙 (반드시 지킨다)

1. **구성 순서**: 국문 제목 → 저자(소속 각주 `*`, `**`) → 영문 제목 → 영문 저자 → 요약 → Key words → 본문(Ⅰ, Ⅱ, … 장 / 1.1 절) → 참고문헌.
2. **요약**: 한 단락. 연구 목적·방법·결과 순서로 쓴다. 3~5문장.
3. **키워드**: 영문 3~5개, 쉼표로 구분한다.
4. **본문 구조**: 서론 → 본론(필요 시 절) → 결론. 장 번호는 로마 숫자(Ⅰ, Ⅱ, Ⅲ)가 자동으로 붙으니 `heading`에는 번호 없이 제목만 쓴다. 절은 `1.1`, `1.2` 형식이 자동으로 붙는다.
5. **인용**: 본문 인용은 `[1]`, `[2]` 대괄호 번호. 참고문헌 순서와 번호를 일치시킨다. 본문에 없는 문헌을 참고문헌에 넣지 않는다.
6. **출처는 클릭 가능한 링크**: 참고문헌의 `http(s)://` 주소는 스크립트가 자동으로 하이퍼링크(파란색 밑줄)로 바꾼다. URL은 그대로 적고, 접속 가능한 실제 주소만 쓴다.
7. **쪽번호**: 모든 쪽 하단 가운데에 자동 삽입된다.
8. **사실 확인**: 통계·인용·URL을 지어내지 않는다. 확인하지 못한 내용은 쓰지 않거나 사용자에게 묻는다.
9. **저자·소속·이메일**: 사용자가 알려 준 것만 쓴다. 추측하지 않는다.
10. **원본 보존**: 템플릿 원본은 수정하지 않고 항상 새 파일로 저장한다.

## 작성 절차

1. 사용자에게 주제·저자 정보·분량을 확인한다. 자료 조사가 필요하면 출처 URL을 실제로 열어 확인한다.
2. `examples/sample.json`을 참고하여 내용을 `paper.json`으로 작성한다.

   | 키 | 설명 |
   |---|---|
   | `title_ko`, `title_en` | 국문·영문 제목 |
   | `authors_ko`, `authors_en` | 저자 줄 (예: `홍길동*, 김철수**`) |
   | `notes` | 저자 각주 목록 (최대 2개, `*`/`**`에 대응) |
   | `abstract` | 요약 한 단락 |
   | `keywords` | 키워드 배열 |
   | `sections` | `[{heading, paragraphs[], subsections[{heading, paragraphs[]}]}]` |
   | `references` | 참고문헌 문자열 배열 (URL 자동 링크) |

3. 생성한다.

   ```text
   python <이 스킬 경로>/scripts/make_paper.py paper.json output.hwpx
   ```

4. 검사한다.

   ```text
   python ~/.claude/skills/hwpx/scripts/fill_hwpx.py check output.hwpx
   ```

   `"ok": true`, `errors: []`를 확인한다.
5. **마지막 확인은 사람 눈으로**: 한컴오피스에서 열어 쪽 모양, 링크 클릭, 쪽번호를 확인하도록 사용자에게 안내한다. 정적 검사 통과는 화면 확인을 대체하지 못한다.

## 주의

- `scripts/make_paper.py`는 hwpx 스킬 스크립트를 import하므로 `-I`(격리 모드) 없이 실행한다.
- 템플릿 자체를 한컴오피스에서 열면 `{{...}}` 자리표시자가 있는 빈 양식으로 보인다. 직접 손으로 채워도 된다.
